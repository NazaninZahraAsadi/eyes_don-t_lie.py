🌈 Eyes Don't Lie

A Creative Python Animation Project

An experimental animation created with Python's Turtle Graphics library.

The project combines mathematical curves, continuous color transitions, smooth movement, and animated text to create a colorful visual experience.

✨ Features

- Mathematical Wave Generation: Creating a wavy circular shape using sine functions.
- Continuous Rainbow Colors: Generating smooth color transitions using the HSV color model.
- Smooth Animation: Implementing movement with the Smoothstep interpolation function.
- Animated Turtle Movement: Rotation, scaling, and disappearance effects.
- Animated Typography: Displaying text character by character.
- Pulsating Waves: Creating animated rainbow waves with changing phases and scales.

🚀 How to Run

1. Make sure Python is installed.
2. Save the source code as "eyes_dont_lie.py".
3. Run the following command:

python eyes_dont_lie.py

Note: This project requires a graphical environment that supports Python Turtle.
